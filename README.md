# checkhtml

Check numeric html values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/checkhtml/

## Install / run

```bash
git clone https://github.com/theworker02/checkhtml.git
cd checkhtml
node src/cli.js
node --test
```
